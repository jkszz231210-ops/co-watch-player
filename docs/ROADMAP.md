# Roadmap

## P0 · 共视感原型（当前）

目标：证明“播放器有自己的意图”可以成立。

- [x] 本地多视频片单
- [x] 自定义基础控制
- [x] 时间争夺
- [x] 暂停争夺
- [x] 临时倍速干预
- [x] 跨视频串台与返回
- [x] 本地关系记忆
- [x] 音频能量驱动 UI 状态
- [ ] 收集真实使用时“有趣 / 烦人 / 像 Bug”的时刻

## P1 · 从随机走向感知

目标：它为什么这么做，开始有因果。

- [x] 音频静默检测
- [x] 音量突变检测
- [x] 场景切换检测（低分辨率帧差原型）
- [x] 画面运动强度
- [x] 画面亮度采样
- [x] 主色粗估并驱动时间轴染色
- [x] 字幕活跃度采样（浏览器可暴露 textTrack 时）
- [x] 用户重复回看片段识别
- [x] 用户暂停热点
- [x] 建立统一 `PerceptionFrame`
- [x] 每次干预记录内部 reason 与当时感知快照

## P2 · Player Mind

目标：把感知变成长期性格。

核心模块：

```text
Perception -> Memory -> Mood -> Desire -> Decision -> Action
```

- Mood：安静 / 好奇 / 紧张 / 无聊 / 执拗
- Desire：继续看 / 回看 / 跳过 / 联想 / 保持沉默
- Relationship：陌生 -> 试探 -> 熟悉 -> 默契 -> 共生
- 个体差异：不同安装实例逐渐形成不同习惯

## P3 · 真正桌面播放器

目标：从浏览器原型迁移到可长期使用的软件。

建议技术路线：

- Tauri 桌面壳
- React / Solid 前端
- libmpv 播放内核
- Rust 侧统一控制 mpv
- SQLite 记忆库
- FFmpeg 分析任务
- Windows 首发

## P4 · 联想系统

目标：串台不再随机。

例如当前画面出现“雨”，播放器从本地媒体库寻找：

- 相似雨景
- 相似颜色
- 相似对白
- 同演员 / 人物
- 用户曾反复观看的片段
- 多年前暂停过的某个瞬间

然后决定是否短暂“想起”它。

## P5 · 更危险也更有意思的实验

以下全部应作为可配置实验，而不是默认开启：

- 主动改变字幕
- 主动隐藏部分 UI
- 根据注意力退出 / 进入全屏
- 关闭时迟疑
- 对用户连续跳过某段内容产生反应
- 同一视频第二次观看时表现不同
- 记住用户曾错过的片段并在未来重新呈现
- 多视频之间形成“梦境式”拼接
