# 03 · 表情、Cubism 参数与演出设计 V1

## 结构

- **常驻层**：随机化自然眨眼、呼吸、眼球微动、极小幅度肩部与头发物理。
- **情绪层**：开心/疑惑/害羞/小得意等表情状态，用多维权重渐变，不是直接显示静态表情贴图。
- **行为层**：倾听、思考、答复、惊讶、轻点头、偏头；可调强度及持续时间。
- **语音层**：嘴部张合依赖 TTS 音频包络；提高要求后用音素时间戳及不同口型关键形。

## 实际 Cubism 参数（建议，正式绑定需核对模型具体 ID）

| 模块 | Cubism 标准或建议的参数 ID | 目标 |
|---|---|---|
| 头部姿态 | `ParamAngleX`, `ParamAngleY`, `ParamAngleZ` | XY 头部方向与 Z 倾斜（示例范围 ±30°） |
| 眼睛开合 | `ParamEyeLOpen`, `ParamEyeROpen` | 左右眼独立眨眼 |
| 笑眼 | `ParamEyeLSmile`, `ParamEyeRSmile` | 眼尾变化，笑意进眼睛 |
| 眼球方向 | `ParamEyeBallX`, `ParamEyeBallY` | 视线与轻微跟踪 |
| 眉毛 | `ParamBrowLY`, `ParamBrowRY`, `ParamBrowLAngle`, `ParamBrowRAngle` | 左右眉不同步/疑惑 |
| 嘴部 | `ParamMouthOpenY`, `ParamMouthForm` | 张合与笑/苦的口型 |
| 身体 | `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ` | 呼吸/倾斜/重心转移 |
| 呼吸 | `ParamBreath` | 正常呼吸周期 |
| 自定义附加 | `ParamBlush`, `ParamTear`, `ParamPupilScale` 等 | 腮红/泪光/瞳孔特效，需在模型中真正建立 |

**注意**：上表列举的 ID 不意味着最终模型已具有这些参数，部分为自定义扩展。不要混淆动画行为模型中简化的 `eyeOpen` 与真正的左右眼参数。

## 状态机与参数融合

行为控制器拥有 `idle`、`listening`、`thinking`、`speaking`、`reaction` 五种高层状态；情绪为跨状态、可调权重的维度。建议规则：

- 突发事件先使用 150–280ms 的短暂惊讶峰值，再过渡到目标情绪 300–700ms；不要所有动作同步到达最大值。
- 当说话开始，优先级：安全边界 > 嘴型 > 手动表情与动作 > 常驻自动眨眼/呼吸；同一参数冲突时必须显式定义覆盖与混合策略。
- 讲话张嘴不能覆写嘴角情绪形态；口型张合和情绪嘴形是不同参数。
- 视线的微动间隔应有变化但不能随机抽动；平静模式停顿更长。
- 对用户话语的情绪判断有不确定度时，选择自然的轻微关注，而非强行夸张生气/害羞。

## 三段式场景验收

`你真可爱` → 160ms 注意力抬升 → 300ms 眼神偏移 → 500ms 腮红 + 小微笑 → 说话口型 → 逐渐恢复。 

`我今天好累` → 眼神稳定 → 眉尾柔和下移 → 轻轻点头 → 回复时缓慢张合嘴型 → 保持认真倾听。 

`我成功啦！` → 睁眼/眉毛短暂抬升 → 轻笑 → 头发顺势运动 → 说话时嘴型保留开心程度。

## 网页原型现状

`web/js/character-engine.js` 已有 16 态和连续插值，**仅供交互 UI 参数演示**。正式 Live2D 阶段应在 renderer adapter 中接入真正的模型。切勿把这六个抽象数值作为已绑定的 `.moc3`。
