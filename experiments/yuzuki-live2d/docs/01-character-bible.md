# 01 · 柚希 Yuzuki：美术与角色设定 V1

> 临时代号：柚希（ゆずき / Yuzuki），可在定稿前更名。**角色定位优先于命名。**

## 一句话人物定义

初见清冷知性，眼睛里藏着温柔；熟悉以后会有一点笨拙的害羞、机灵的小得意，偶尔安静得像月色下的水。**核心必须可爱，但不是幼态化。**

## 性格表现层次

| 层次 | 重点 | 视觉锚点 |
|---|---|---|
| 主调：可爱且温柔 | 无压迫感、愿意亲近 | 柔和杏眼、轻微笑意、圆润柔和面颊 |
| 次调：清冷知性 | 安静、善于倾听与思考 | 低饱和灰蓝瞳、简洁精细的线稿 |
| 动态：灵动 | 微表情有节奏、会偷偷偏头 | 眉眼非对称、目光闪烁、细微头部运动 |
| 点缀：梦幻 | 一点遥远感，不喧宾夺主 | 蓝灰花饰、轻盈发梢与极轻的光点 |

## 外观硬约束

- 视觉年龄：成年年轻女性的动画化形象；避免明显儿童式比例。
- 脸型：柔和的小鹅蛋脸，略带圆润脸颊，下巴收束自然，拒绝刀削尖下颌。
- 眼睛：偏大的杏眼，外眼角略微延伸，虹膜灰蓝、中心微亮、外环深蓝灰；左右眼要分别绘制。
- 眼神：默认看向交流对象，但允许短暂偏移；虹膜高光保留 2–3 个主要层级，避免满眼碎亮点。
- 眉毛：较细、柔和、略弯，眉尾可独立抬落，非对称变化要自然。
- 鼻与嘴：动画化简化鼻形；小巧嘴型、柔和唇线，口腔内层具备牙齿与舌头可选变形空间。
- 发型：深黑茶、透出淡冷灰色反光的中长发/长发；轻盈而有分组逻辑的空气刘海，左右修脸发束，后发分段摆动。
- 标志性饰品：**右侧蓝白小花 + 极细蓝色发带**。作为记忆点，但避免复杂簪饰堆叠。
- 服装：米白与冷蓝灰的简洁轻制服/连衣上衣、领口小蝴蝶结，轻柔褶边，较少金属件。
- 色彩参考：头发 `#363748`、亮部 `#636577`、虹膜 `#8299BC`、深虹膜 `#506786`、主服装 `#F5F4F0`、副服装 `#A5B6D5`、点缀 `#6A81AD`、皮肤 `#F7DDE0`。都是建议值，最终以插画校色为准。

## 审美风险与纠偏

- **过度堆饰物**：不把一堆簪子、金属、蕾丝、蝴蝶结当作精致。保留标志花饰和领口蝴蝶结即可。
- **脸被长刘海吃掉**：眉眼区域必须清晰，刘海至少给眉眼留出自然空间。
- **眼睛平面化**：瞳孔、虹膜纹理、高光的空间层次清晰，眨眼后不留不合理残像。
- **脸转动时不协调**：耳朵、眉眼、鼻、嘴、脸廓转动幅度不应全都一致平移。
- **永远同一种笑**：小心反应速度、视线、眉毛左右非对称与停顿组合，避免贴纸表情。

## 目标视觉素材

1. **干净的正面标准设定**：眉眼完整、自然闭嘴、肩部端正、留足脸周空间，作为最终 PSD 基线。
2. **45 度 3/4 侧面辅助图**：明确发际、耳朵、颧部遮挡结构，仅作为绘制/绑定参考，不是直接套用贴图。
3. **情绪板（16 态）**：同一人设、同一五官位置和配色，保证一眼可辨。
4. **服装层级设计**：胸前蝴蝶结、衣领、外侧袖装/上衣主层，预留身体倾斜的遮挡区。

当前 `assets/source/` 两张图是**角色初版方向稿**，人物细节及装饰密度尚未完成统一修订；未来 PSD 绘制应以“干净的正面标准设定”为唯一主要依据，而不是直接复制设定板的所有装饰。
