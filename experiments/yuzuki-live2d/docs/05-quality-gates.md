# 05 · 质量门禁与验收

## G0 · 静态审美冻结（先完成）

- [ ] 无妆感堆叠，第一眼是可爱、温柔、知性且成年感自然的日系二次元角色。
- [ ] 提供正面标准稿、3/4 侧面参考与 16 态情绪板，人物脸型、眉眼位置和饰品左右完全一致。
- [ ] 黑茶长发与灰蓝眼是识别点，右侧蓝白花饰是唯一强装饰中心；把当前概念图多余饰物收敛。
- [ ] 同一角色在缩小到网页角色 320px 高时仍能辨认脸部神态。
- [ ] 基准稿自然平视，不依赖大角度、灯效和背景遮住五官瑕疵。

## G1 · PSD 制作验收

- [ ] 各组分层符合 `02-art-production.md`，未见大面积错误透明挖空。
- [ ] 刘海、侧发移开时额头/耳朵/脸颊完整。
- [ ] 张嘴与上下眼睑极值时能看到正确的隐藏材质。
- [ ] 已交付真正可编辑、分层正确的 PSD，而非把 PNG 另存为 PSD。

## G2 · Cubism 验收

- [ ] `ParamAngleX/Y` 在范围内平滑变形，两侧侧脸与发际线无拉扯崩坏。
- [ ] 左右眼独立眨眼，闭眼没有残留虹膜高光。
- [ ] 微笑、嘟嘴、惊讶 O 嘴至少各完成 3 个过渡关键形。
- [ ] 两侧眉毛单独改变，疑惑/委屈/小得意不是换一张贴图。
- [ ] 发束摆动、领结、呼吸有合理幅度，不出现持续振荡。
- [ ] 16 态演出逐项走查，在 30fps 与 60fps 下表情切换稳定。

## G3 · 交互验收

- [x] 当前原型可点击 16 种情绪，展开静态概念预览。
- [x] 原型六个抽象参数可查看插值状态。
- [x] 模拟文字聊天可以得到不同情绪；可选浏览器语音朗读。
- [ ] 真实 `.model3.json` 模型渲染运行。
- [ ] 连贯口型与语音同步。
- [ ] 真实聊天服务接入和错误处理。
- [ ] 桌面封装、移动端性能与内存长时间运行验证。

## 推荐实测场景

1. 害羞时从正面转头，眼睛、耳朵、发饰不能跳位。
2. 听用户说很难过，角色不应还持续大笑。
3. 连续切换惊讶→害羞→温柔，嘴型始终可控，避免参数打架。
4. 快速朗读、暂停、重新播放，口型不能残留在张嘴状态。
5. 1366×768、1440×900、1920×1080、手机 390px 宽均可正常使用。
6. 禁止自动播放语音，用户须明确打开朗读。
