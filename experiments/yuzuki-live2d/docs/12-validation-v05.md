# 柚希 V0.5 验证记录

## 已通过的自动验证

- `npm run check`：JS 模块语法检查通过。
- `npm test`：25 项单元测试通过，包括角色配置、审美锁定、表情参数、三种故事演出、自然眨眼、口型和响度映射。
- `python tools/validate_release.py`：29 个 DOM ID 引用可解析，JS import 路径、基础图像、分层 ORA 与四个图层、定稿立绘 SHA-256 均核对通过。
- `tools/render_qa_previews.py`：离线模拟生成六状态视觉对照图与 54 帧循环动画。

## 尚未完成或没有宣称通过的验证

- Chromium 环境的端到端浏览器导航/截图受容器权限与本地端口访问限制，**没有通过图形端到端测试**。
- 麦克风权限、Web Speech 浏览器版本差异、真实设备上声音到嘴型的延时，仍需要在用户电脑确认。
- 眼睑线条、头部转向、眉毛独立变形及真正 Cubism 绑定未达到正式验收标准。

## 已知视觉问题

- 眨眼仍采用眼睛局部缩放和程序化闭眼线条，不是美术精修的上下眼皮插值。
- 不同嘴型为基于曲线的近似，精细牙齿、舌头、嘴角肌肉没有对应分层。
- 眼神跟随只移动小范围眼部图像，不能大幅左右转向。

## 人工验收入口

解压 V0.5 ZIP → 双击 `一键体验柚希.cmd` → 点击「动作参数」→ 依次试「眨眼一次」「口型 A / I / O」「麦克风驱动嘴型」「保存当前画面」。
只需要审核实际脸部观感，无需再审核已经锁定的人设。
