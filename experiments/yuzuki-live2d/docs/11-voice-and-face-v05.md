# V0.5 语音与面部演出说明

## 本轮落地范围

- 保持用户已选定的 `assets/source/yuzuki-front-a.png` 不变。
- 面部渲染仍采用自动提取的眼部与嘴部透明图层：`web/assets/face-rig`。
- `face-performance.js`：不规则眨眼、参数归一化、五种口型目标、基于文字的节奏估计、麦克风响度映射。
- `facial-art.js`：Canvas 局部眼睑线条、唇线/口腔曲线、可控腮红叠加。属于程序化绘制，不等于画师手绘图层。
- `audio-mouth.js`：用户点击按钮、授权麦克风后，WebAudio 本地计算波形 RMS，再驱动嘴部张合。未上传音频。
- `raster-face-rig.js`：保持底图不动，重绘两个独立眼区及嘴区，并支持受控试验姿态。眼神跟随限于很小的移动幅度，避免破坏原画。

## 你可以亲自看的 5 项

1. 运行 `一键体验柚希.cmd`，查看主界面是否始终为已审核的中间立绘。
2. 「动作参数」→「眨眼一次」，观察两眼闭合与重开。
3. 「动作参数」→「口型 A / I / O」，比较宽口与圆口。
4. 「动作参数」→「🎤 麦克风驱动嘴型」，授权后说话，对比轻声和正常音量；停止后检查浏览器麦克风图标已结束。
5. 「📸 保存当前画面」，保存 PNG 看看五官有无重影/断线。

## 音频限制

- 浏览器的 `speechSynthesis` 不提供可读的输出 PCM；因此朗读模式仅用 `boundary` 事件和文字节奏估计口型。**不声称音素级同步。**
- 麦克风模式是真实输入音量驱动，但只根据音量改变张合，尚未识别元音或音素。
- 只有用户主动点击按钮才调用 `getUserMedia`；在 `localhost` 或 HTTPS 下使用。随时可停止，且关闭页面会关闭流。
- 文本聊天仍为离线规则样例，不是真实 LLM。

## 视觉边界与风险

- V0.5 的眼睑、眉毛与面部补画尚不足以通过专业 Live2D 绑定验收。闭眼线条是程序化线条。
- 头像整体不支持 Cubism 真正头部 XY 转向，头发也没有细发束独立物理运动。
- 「16 种表情」仍表示角色意图与参数目标，而非 16 套已完成、逐帧精修的表情模型。
- 这套技术可以用于原型、网页看板娘与行为系统验证；要实现专业 Live2D，仍需绘制完整分层 PSD 并在 Cubism 中绑定。
