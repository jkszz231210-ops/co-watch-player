# 柚希 V2.0 眼部演出与美术交接

本版本针对 V1.1 机械抠图、双重眼线和左右视觉不协调问题。原始立绘仍是唯一可信的默认眼型标准。

## 技术改动

1. `tools/build_blink_v15.py` 的 `frame(side,c,draw_lash=False)` 允许生成纯净的眼睑遮挡底图，移除历史图层重复画眼线的问题。
2. `tools/build_eye_keyforms_v20.py` 在遮挡底图上仅绘制**一条渐细眼线**，采用独立分区的曲线，不把左眼强行镜像到右眼。
3. `web/js/blink-v20.js` 每帧仅合成一张贴图，避免两帧 alpha 混合再次造成重影；0% 闭合直接跳过绘制，完全保留原画。
4. 输出 41×2 帧无损 WebP、8 层 PSD、原画/旧版/新版对照、HTML 审核页和 GIF。
5. 独立 Chromium 桌面与手机浏览器回归测试覆盖审核页、陪伴页和挂件。

## 美术待办（未完成）

- 半闭眼时的皮肤与眼线仍由几何曲线近似，离专业画师的层次还有明显差距。
- 眼角牵引、上下睫毛、左右眼皮厚度、刘海遮挡处需要绘画师精修。
- PSD 是绘画交接与眼部关键形参考，不是 Cubism .cmo3 或 .moc3 模型。
- **必须经过人工审美审核后** 才将这些局部图层作为正式 Cubism 绑定底稿。

## 验收方式

打开 `柚希-V2.0-眨眼成品审核.html`，先检查 50%、75% 和闭眼。看颜色接缝、眼角、残留睫毛与左右眼闭合顺序。不满意时直接指明画面位置，不必重新选脸。
